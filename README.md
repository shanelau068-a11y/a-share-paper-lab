个人模拟学习网页原型，初始10万元虚拟资金，无真实交易能力。原型独立编写，没有集成或声称复刻Qlib、RQAlpha或VeighNa完整引擎。

## 运行

需要Node.js 22或更新版本。无需安装依赖。

```sh
npm test
npm start
```

打开 http://127.0.0.1:4186 。`npm run build` 生成Worker和静态资源；`node scripts/prepare-pages.mjs` 将静态应用放入docs/，供GitHub Pages部署。GitHub Pages版从浏览器直接读取第三方行情，不经过本地服务器。访问本地网址加`?direct=1`可验证同一数据路径。

## 已实现

- 30只固定沪深主板股票，3只A股宽基ETF；公开腾讯报价和100根未复权日线，注明时点。
- 已完成日线上的透明技术规则，最多10只股票候选，可为零，不覆盖全市场。
- 虚拟限价单、手动撤单、持仓、成本、交易费用、成交记录、单标的20%上限。
- 按刷新时有效买一/卖一和一档数量，计0.05%不利滑点；过期报价、涨跌停、缺档、T+1限制。
- 本浏览器账户保存、JSON导入导出；收盘后当日首次刷新留档候选。
- 响应式中文界面。没有真实券商、资金、密钥或个人职业资料。

## 明确限制

- 打开页面才刷新撮合，关闭后没有后台交易或主动通知。没有收益承诺、AI预测或已验证盈利策略。
- 不完整模拟交易所撮合队列、部分成交、订单资金冻结、价格笼子、除权除息、交易日历、盘后及集合竞价。已识别持仓跨公司行为时暂停撮合；公司行为和股息未结算会影响收益。
- 未复权历史存在分红价格断点，因此近21个日线发现公司行为时不出候选。旧公司行为仍可能影响60日均线。股票池有选择偏差，没有退市历史/全市场生存偏差控制。
- 分红/送转识别仅依赖近期日线附带信息，不能替代完整公司行为数据；长期持仓须自行核对。资产表现是价格与模拟费用记账，不是严谨总回报回测。
- 行情接口为第三方公开接口，可能延迟、改变或中断；本项目没有行情商SLA或再分发授权。商业化前需另行确认许可。数据失败不使用造价替补。
- 账户仅localStorage，不跨设备云同步，清缓存可能丢失。导入是替换本地虚拟账户。
- 本地API仅提供行情查询，暂无写入服务端账户。GitHub Pages网页及此仓库公开；模拟账户仅保存在访问者当前浏览器，未上传服务器。用户于2026-10-14明确同意公开模拟器代码和长期网址，不包括其聊天与个人资料。
